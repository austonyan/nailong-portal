# 05 · Layouts 页面与响应式

> 这一层回答“页面怎么排、窗口变化时怎么重排”。
> 先决定信息关系（谁最重要、谁和谁一组），再选模板；不要从 375px/1440px 两张固定画板倒推。
> 交付目标是**规则一致**，不是某一画板下逐像素不动：窗口缩放、横竖屏、分屏、折叠屏和 200% 字号都要能重排。

---

## 1. 布局原则

1. **一个页面一个主任务**：主操作只出现一次；其余操作降级到 default/text 或详情。
2. **容器边界一致**：同类内容左对齐到同一条线；卡片网格的最左/最右边界一致。
3. **先定宽，再排内容**：页面最大 1440px；正文/详情最大 960px；表单最大 960px；个人资料 640px。
4. **中间尺寸也要活**：不只看 375 与 1440，还要看 640 / 720 / 900 / 1024 / 1280。
5. **高度不锁死**：文本容器用 `min-height`，不用固定 `height`；中文/繁体/200% 缩放都要能长高。
6. **不横向滚动**：页面、表格、弹窗都不能出现横向滚动条；长内容换行或进详情。

---

## 2. 全局外壳

```
┌────────────────────────────────────────────────────────────┐
│ header (sticky, z=100, max 1440, padding 10/24)             │
├──────────┬─────────────────────────────────────────────────┤
│ sider    │ main (max 1440, padding 24)                     │
│ 260px    │                                                 │
│ sticky   │                                                 │
│          │                                                 │
├──────────┴─────────────────────────────────────────────────┤
│ footer (center, 12px, padding 20)                          │
└────────────────────────────────────────────────────────────┘
```

| 区域 | 尺寸 / 规则 |
| --- | --- |
| 顶栏 | sticky top 0；内容最大 1440；左右 padding 24；高约 53px（由内容撑开，不写死） |
| 侧栏 | 260px；sticky；自身滚动；`z-index: 110`；`background: --animal-bg-color-secondary` |
| 主内容 | 最大 1440；padding 24；`min-width: 0`（防止 flex 子项撑破） |
| 页脚 | 居中 12px；不需要吸底 |
| 移动端 | ≤1024 侧栏进 Drawer（280px）；≤640 顶栏换行、顶栏 padding 16（页面主 padding 仍 24） |

- `.app-shell` 用 flex；`.app-body` `flex:1; min-width:0`；`.app-main` `width:100%`。
- 侧栏折叠后内容仍居中，不因侧栏消失而偏移。
- 页面内不要出现第二个 sticky 顶栏；署内导航随内容滚动。

## 3. 断点

项目实际使用 640 / 720 / 900 / 1024 / 1440。新代码只使用这五档（360 是验收最小宽度）。

| 断点 | 名称 | 主要变化 |
| --- | --- | --- |
| ≥1440 | Wide | 内容 1440 居中；卡片网格 4–5 列（有无侧栏不同） |
| 1025–1439 | Desktop | 侧栏常驻；卡片 2–4 列（按可用宽度）；表格全列 |
| 901–1024 | Small desktop | 侧栏收进 Drawer；卡片 2–3 列；筛选条可换行 |
| 721–900 | Tablet | 卡片 2 列；详情字段仍左右排；表格压缩换行 |
| 641–720 | Large phone | 卡片 1–2 列；筛选条纵向堆叠；表单开始单列 |
| ≤640 | Phone | 顶栏换行、顶栏 padding 16；卡片 1 列；表单单列；详情标签在上；按钮可全宽 |
| ≤360 | Min | 最小验收；不能出现横向滚动；长编号换行 |

> 断点是“重排规则”，不是“设备型号”。折叠屏/分屏按可用宽度落档，不按设备名。

## 4. 页面模板

### 4.1 门户首页

```
[Hero: Background sprinkles + Title large + Typewriter 标语]  36/32 padding
[Stats: 3 × Card, grid minmax(220,1fr), gap 16]
[Divider wave-yellow]
[Section Title + 服务卡 grid minmax(240,1fr), gap 16]
```

- 内容最大 1440；hero 与卡片同宽。
- ≤640：hero padding 24/20，标题 24–28，统计卡 1 列，服务卡 1 列。
- 统计卡数字不换行；标签可换行。

### 4.2 署首页

```
[Office banner: 徽标 44 + 署名/副标题]
[Horizontal nav: pill links, wrap]
[Hero: 34/32 + 3 个入口按钮]
[Scam banner / 公告 / 类型卡 / 指南 / FAQ / 支持卡]
```

- 区块间距 24px（现有 22px 就近归一）。
- 类型卡/指南卡 `minmax(240,1fr)`；公告单列。
- ≤900：hero 按钮换行；≤640：按钮纵向、类型卡 1 列、FAQ 全宽。
- 横向导航 `flex-wrap: wrap`；不要横向滚动。

### 4.3 列表 / 工作台

```
[page-header: Title (h1) + 筛选/操作]
[Card]
  [Table table-fit]
  [Pagination]
[/Card]
[Drawer 详情] [Modal 动作]
```

- 全宽（最大 1440）；表格在 Card 内，Card 不再套 Card。
- page-header 与 Card 间距 16；Card 内表格与分页间距 8–14。
- 筛选条：桌面一行；≤900 换行；≤640 每个控件占满一行。
- 表格：最多 8 列；超过时把次要字段移入详情 Drawer。操作列固定最后。
- ≤640：列宽压缩、表头换行、操作按钮换行；仍不横向滚动。

### 4.4 详情页

```
[page-header: Title + 状态 Tag]
[状态横幅（可选）]
[Card > 字段列表 dl]
[Card > 材料列表]
[Card > 审核时间线]
[操作区]
```

- 内容列最大 **960px**（宽屏不要拉满 1440，阅读行长更舒服）；表格/材料多时可用 1100px。
- 字段行：`dt` 110px + `dd` flex；≤640 改为上下排（`dt` 在上，`dd` 在下）。
- 时间线、材料列表与字段列表同宽。
- 状态横幅在字段列表之前；操作区在最后，主操作右对齐（移动端全宽）。
- 打印时隐藏外壳与操作区（见 §9）。

### 4.5 表单 / 申请

```
[Title + 草稿号]
[Card > Form vertical]
  [两列 grid: minmax(220,1fr), gap 16/0]
  [文本域跨列]
[Card > 材料上传]
[底部操作: 保存草稿 | 提交申请]
```

- 内容列最大 **960px**。
- 两列只在 ≥720 使用；≤640 单列。
- 同一行控件同尺寸（large）。
- 材料卡与表单卡间距 16；上传行在窄屏纵向。
- 底部操作：桌面右对齐；≤640 两个按钮各占一半或全宽，主操作在后。
- 长表单分节，每节 `<h3>` + Card；不要一屏到底没有分组。

### 4.6 登录 / 注册 / 首次引导

| 页面 | 卡片宽 | 布局 |
| --- | --- | --- |
| 登录 | 400px | 单列；Title + 副标题 + 表单 + block 主按钮 + 链接 |
| 注册 | 400px | 同上；字段更多，仍单列 |
| 首次引导 | 580px | 顶部语言；Card 内 Step 内容；Progress；底部上一步/下一步 |

- 页面背景 `Background type="sprinkles"`；卡片居中；页面 padding 24。
- ≤640：卡片宽 100%，padding 20；按钮全宽。
- 引导步骤不能因为内容长短跳动：内容区用 `min-height` 保持稳定。

### 4.7 公共验真页

- 无应用外壳；顶部只留品牌 + 语言；主体最大 640px 居中。
- 输入 + 查询按钮一行（≤640 纵向）；结果卡在下方。
- 结果卡：结论（大号）+ 图标 + 字段列表 + 时间；不要用大面积红色/绿色底压白字。

### 4.8 打印

- A4 纵向；建议 `@page { size: A4; margin: 16mm; }`（当前未声明，新增打印页应补）。
- 隐藏：顶栏、侧栏、页脚、署内导航、筛选、按钮、遮罩、Toast。
- 纸白底、深棕/黑字；边框 1–2px；QR 白底留白；印章/状态用文字重复。
- 避免跨页断裂：证书/签注单页；长决定书用 `break-inside: avoid` 包住签章块。
- 打印按钮是同步动作；不弹 loading。

## 5. 栅格与间距

| 场景 | 规则 |
| --- | --- |
| 服务/类型/指南卡 | `repeat(auto-fill, minmax(240px, 1fr))`，gap 16 |
| 统计卡 | `repeat(auto-fit, minmax(220px, 1fr))`，gap 16 |
| 表单两列 | `repeat(auto-fit, minmax(220px, 1fr))`，gap 0 16 |
| 详情字段 | `dt 110px + dd flex`，行 padding 8 0，2px dashed 分隔 |
| 页面区块 | 垂直 gap 24；页面头与内容 16 |
| 卡片内 | padding 16/24；标题与正文 8–12 |
| 按钮组 | gap 12（弹窗底部）/ 8（行内）/ 4（表格操作） |

- 页面主容器用 `display:flex; flex-direction:column; gap:24px`，不要靠一串 `margin-top`。
- 卡片网格的最小列宽是下限；不要写死 `width: 240px`。
- 两栏内容（如详情 + 侧栏）当前未使用；如新增，主栏 `minmax(0,1fr)` + 侧栏 320px，≤900 改单列。

## 6. 表格布局

### 6.1 列策略

| 优先级 | 列 | 处理 |
| --- | --- | --- |
| P1 | 编号、状态、操作 | 始终可见；编号可换行；状态用 Tag；操作最后 |
| P2 | 申请人、类型、提交时间 | 保持可见；时间可换行 |
| P3 | 昵称、备注、次要业务字段 | 列多时移入详情 Drawer |

- 最多 8 列；>8 列必须拆表/移详情。
- 列宽用 `width` 提示（120–180），但允许自动压缩与换行。
- 数值列 `align:'right'`；文本左对齐；操作右对齐。
- 不使用 `fixed` 列（页面不横向滚动，fixed 无意义）。
- 表头可换行（`.table-fit th { white-space: normal }`）；长文本 `overflow-wrap:anywhere`。
- 空表：`emptyText`；加载：`loading`；失败：表格外错误条。

### 6.2 窄屏

- ≤640：表头与单元格都换行；操作按钮纵向堆叠；行高自然增长。
- 不隐藏关键列；如果实在放不下，把 P3 列移入详情，而不是横向滚动。
- 分页在表格下方居中；窄屏不显示“每页条数”选择器（保留页码）。

## 7. 弹窗与抽屉尺寸

| 类型 | 宽度 | 场景 |
| --- | --- | --- |
| Modal sm | 460px | 确认、短提示 |
| Modal md | 560px | 标准表单/详情摘要 |
| Modal lg | 640px | 宽表单 |
| Modal xl | 720px | 极宽内容（少用） |
| Drawer nav | 280px | 移动端侧栏 |
| Drawer msg | 440px | 站内信 |
| Drawer detail | 560px | 详情 |
| Drawer wide | 620–640px | 工作台详情/复核 |

- 所有弹层 `max-width: calc(100vw - 32px)`；≤640 时接近全宽。
- 内容高度超过一屏：Modal 内部滚动，footer 固定；Drawer 内容区滚动。
- 不要用 90vw/90vh 的巨幅 Modal；长内容用页面。
- 现有 420/480/520/540/680 是历史值，**新代码只用上表档位**；改到旧弹窗时就近收敛。
  库的 Modal 默认宽 520，不在档位内，必须显式传 `width`。

## 8. 字体缩放与长文案

- 200% 浏览器缩放：页面不横向滚动、按钮文字不被裁切、表格不重叠、弹窗仍可操作。
- 中文/繁体最长文案：按钮、Tab、筛选、表头按 `zh-TW` 校对；按 +30% 文字膨胀预留空间，不要用固定 `width` 截断。
- 文本容器：`min-width: 0`（flex 子项）、`overflow-wrap: anywhere`（长编号/URL）、
  `white-space: normal`（表头）。
- 不使用 `height` 固定文本容器；用 `min-height` + padding。
- 不用 `text-overflow: ellipsis` 处理关键信息；只允许昵称、服务简介等非关键摘要。
- **长用户名**：顶栏只允许 1 行省略，个人资料/详情必须完整显示；不要把 40 字用户名塞进按钮。
- **长标题**：卡片/弹窗标题最多 2 行，超出换行/展开，不用 `nowrap`；区块标题与正文同宽换行。
- **按钮**：文字换行或缩成图标（带 `aria-label`）；≤640 时主操作可全宽，不要撑破卡片。
- **表格**：单元格换行；>8 列把次要字段移入详情 Drawer；见 §6.1。
- 移动端输入控件字号 ≥16px（用 `size="large"`），避免 iOS 聚焦时自动放大页面；筛选 Input 在 ≤640 也升到 16px。
- 系统字体放大/动态字号：不设置 `text-size-adjust: none`；布局按内容撑高。
- **焦点不被 sticky 顶栏遮挡**：可聚焦内容加 `scroll-margin-top: 64px`（顶栏约 53px + 8px）；
  `:focus-visible` 环不能被 `overflow:hidden` 裁掉。
- 必测字符串：40 字用户名、100 字标题、`zh-TW` 最长一句、`NNNN-NNNN-NNNN` 长编号。

## 9. 打印布局

```css
@media print {
  .app-header, .app-sider, .app-footer,
  .visa-nav, .page-header, .no-print { display: none !important; }
  .app-main { max-width: none; padding: 0; }
  .print-paper { border: none; box-shadow: none; }
}
```

- 打印页不要依赖背景色区分状态；用文字/边框。
- 证书/签注：单页 A4；QR 与编号同页；签发机关/日期/有效期完整。
- 长表格打印：表头 `thead` 重复；行不跨页断裂（`break-inside: avoid`）。
- 打印前先关闭所有 Modal/Drawer（或 `display:none` 遮罩），避免空白页。

## 10. 布局反例

| 反例 | 问题 | 正确 |
| --- | --- | --- |
| 页面 `width: 100vw` | 含滚动条时横向溢出 | `width: 100%` + max-width |
| 固定 1440 画板 | 1024/720 挤压 | 栅格 + 断点重排 |
| 表格 `overflow-x: auto` | 移动端横向滚动 | `table-fit` 换行/移详情 |
| 两列表单写死 50% | 长文案/缩放溢出 | `minmax(220px,1fr)` |
| 详情拉满 1440 | 行长过长难读 | 内容列 960 |
| 弹窗固定 800px | 手机溢出 | 460/560/640 + max-width |
| 卡片内套卡片再套 Card | 层级混乱 | 一层 Card + Divider/间距 |
| 每个区块都 sticky | 遮挡内容 | 只有顶栏 sticky |
