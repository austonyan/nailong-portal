

# 一、奶龙国皇家文化旅游署

## 定位与边界

**定位：** 平台旅游、文化体验与打卡收集模块，负责奶龙国世界观内的景点展示、旅游线路、文化内容、入境章收集、成就徽章和活动导览。

**做什么：**
- 景点/打卡点展示与管理
- 旅游线路推荐、主题游线
- 文化内容：世界观介绍、节庆、民俗
- 入境章/纪念章收集
- 成就徽章、打卡任务
- 景点预约/限流（趣味化）
- 旅游攻略、游客评价（可选）
- 联动签注/入境/活动署做旅游场景

**不做什么：**
- 不提供真实旅游服务、不预订真实交通住宿
- 不涉及真实景区、真实文物保护、真实旅游监管
- 不收费、不做真实票务交易
- 不收集真实行程、真实位置、真实身份证件
- 不承诺现实旅游权益

## 前台用户端功能

1. **文化旅游署首页**：景点推荐、主题线路、节庆公告、打卡任务
2. **景点列表与详情**：名称、类型、展示位置、开放状态、简介、打卡点、示意图；筛选与搜索
3. **旅游线路**：主题线路、线路详情、途经景点、预计游玩时长
4. **文化内容**：世界观百科、节庆介绍、民俗故事、文化专题
5. **打卡与收集**：景点打卡、入境章/纪念章收集、打卡记录、收集册展示
6. **成就徽章**：打卡成就、线路完成成就、节庆限定徽章、徽章展示
7. **景点预约**：分时段预约、名额限制、预约记录、取消预约（趣味化）
8. **游客评价**：评分、文字评价、评价展示（需审核，可选）
9. **我的旅游**：我的打卡、我的收集、我的徽章、我的预约、我的评价
10. **消息与帮助**：打卡成功、徽章获得、预约提醒、景点公告；常见问题
11. **个人中心**：聚合我的旅游记录、收集册、徽章

## 后台管理端功能

1. **景点管理**：创建、编辑、上下线、开放状态、标签、示意图
2. **线路管理**：线路创建、景点关联、排序、上下线
3. **文化内容管理**：文章、专题、节庆内容发布与审核
4. **打卡规则配置**：打卡条件、每日限次、防刷规则
5. **徽章管理**：徽章设计、获得条件、发放记录、回收
6. **预约管理**：时段、名额、预约审核、取消、异常处理
7. **评价管理**：审核、屏蔽、举报处理
8. **风控**：重复打卡识别、频率限制、黑名单、异常标记
9. **统计报表**：景点访问量、打卡量、线路完成率、徽章发放量、预约量、评价统计
10. **公告与消息模板**：公告发布、站内信模板
11. **审计管理**：敏感操作审计

## 系统能力

- 统一账号与 SSO 接入
- RBAC 权限，内容编辑、景点管理员、审核员队列隔离
- 打卡状态机、预约状态机、徽章发放状态机
- 打卡编号/徽章编号不可猜测生成
- 二维码打卡（可后置）
- 与签注/入境/活动署联动：旅游签注、入境章展示、活动打卡
- 文件私有存储、站内信、审计日志、限流、错误码、软删除

## 与其他署联动

| 联动方 | 联动内容 |
|---|---|
| 签注申请署 | 旅游签注关联旅游线路；签注页展示旅游推荐 |
| 入境署 | 入境记录关联入境章收集；口岸展示旅游导览 |
| 礼宾与活动署 | 节庆活动打卡、活动专属徽章 |
| 居民登记署 | 居民专属旅游线路、居民徽章 |
| 文书与认证署 | 打卡证书/纪念证书认证（可选） |
| 个人中心 | 聚合我的打卡、收集册、徽章、预约 |
| 统一验真中心 | 打卡证书/纪念证书验真（可选） |

## MVP 建议先做

1. 首页 + 景点列表/详情 + 文化内容展示
2. 打卡功能、打卡记录、收集册
3. 单类徽章：打卡成就徽章
4. 后台景点管理、打卡规则、徽章发放、基础统计
5. 站内信、审计日志、权限隔离、限流
6. 与签注署/入境署基础展示联动

后续再做：线路、预约、评价、二维码打卡、节庆限定、居民/外交专属、证书认证、统计大屏。

# 二、奶龙国皇家邮政与通信署

## 定位与边界

**定位：** 平台消息、公告订阅与虚拟邮政体验模块，负责站内信、通知模板、公告订阅、虚拟明信片和通信记录。它既是平台通知基础设施的前台化，也提供趣味邮政体验。

**做什么：**
- 站内信统一收发、已读/未读、归档
- 公告订阅、分类订阅、推送偏好
- 通知模板管理与变量替换
- 虚拟明信片：发送、接收、收藏
- 通信记录、消息搜索
- 邮政编号、明信片验真（趣味化）
- 为各署提供统一通知能力

**不做什么：**
- 不替代真实邮政、快递、物流
- 不发送真实短信/邮件（MVP 只站内信）
- 不涉及真实通信监管、真实信件寄递
- 不收费、不做真实邮票交易
- 不收集真实地址、真实手机号（除非用户自愿且最小化）
- 不承诺现实送达

## 前台用户端功能

1. **邮政与通信署首页**：公告、订阅入口、明信片入口、消息中心入口
2. **消息中心**：全部消息、未读、已读、归档、按署筛选、搜索
3. **公告订阅**：公告分类、订阅/取消订阅、推送偏好、订阅记录
4. **虚拟明信片**：选择模板、填写祝福语、选择收件人（平台用户）、发送、接收、收藏、删除
5. **明信片模板**：节庆模板、景点模板、活动模板、居民/外交专属模板
6. **通信记录**：发送记录、接收记录、明信片编号、状态
7. **明信片验真**：输入明信片编号查询（趣味化，脱敏展示）
8. **通知偏好**：哪些署的通知接收、免打扰时段（站内）
9. **帮助**：常见问题

## 后台管理端功能

1. **通知模板管理**：模板创建、变量、预览、启停、版本管理
2. **公告管理**：发布、编辑、下线、分类、订阅推送
3. **消息管理**：消息查询、重发、撤回（限未读）、异常处理
4. **明信片模板管理**：模板设计、上下线、分类
5. **明信片管理**：发送记录、举报处理、违规内容审核
6. **订阅管理**：订阅分类、订阅统计、退订处理
7. **风控**：发送频率限制、垃圾消息识别、黑名单、举报处理
8. **统计报表**：消息量、已读率、公告订阅数、明信片发送量、举报量
9. **审计管理**：敏感操作审计、内容审核

## 系统能力

- 统一账号与 SSO 接入
- 站内信服务：发送、已读、归档、搜索
- 通知模板引擎：变量替换、多语言预留
- 公告订阅服务
- 明信片状态机：草稿、已发送、已接收、已收藏、已删除
- 明信片编号不可猜测生成
- 与各署通知事件对接
- 文件私有存储、审计日志、限流、错误码、软删除

## 与其他署联动

| 联动方 | 联动内容 |
|---|---|
| 全部业务署 | 提供站内信发送能力、通知模板 |
| 签注/入境/居民/外交/文书/活动/申诉 | 各署业务事件触发站内信 |
| 文化旅游署 | 景点/节庆明信片模板 |
| 礼宾与活动署 | 活动通知、活动明信片 |
| 个人中心 | 聚合消息中心、订阅、明信片 |
| 统一验真中心 | 明信片编号验真（趣味化） |

## MVP 建议先做

1. 首页 + 消息中心 + 公告订阅
2. 站内信统一收发、已读/未读、归档
3. 通知模板管理、与签注/入境署事件对接
4. 单类虚拟明信片：节庆/景点模板，发送与接收
5. 后台模板管理、公告管理、基础统计
6. 审计日志、权限隔离、限流

后续再做：多模板、订阅分类、明信片验真、免打扰、举报处理、短信/邮件通道（需合规评估）。

# 三、奶龙国皇家档案与记录署

## 定位与边界

**定位：** 平台档案归档、记录查询与数据自助管理模块，负责将各署业务记录归档、提供本人记录查询下载、数据删除申请和档案证明。它是平台记录的统一出口，不是现实档案馆或户籍档案机构。

**做什么：**
- 各署业务记录归档：签注、入境、居民、外交、文书、活动、申诉
- 本人档案查询、下载、导出
- 档案编号、档案目录
- 数据删除/注销申请受理与流转
- 档案证明：联动文书与认证署出具虚拟档案证明
- 归档记录验真
- 档案访问日志与隐私保护

**不做什么：**
- 不替代现实档案馆、人事档案、户籍档案
- 不保存真实身份证、护照、人脸等敏感信息
- 不向第三方提供真实档案查询
- 不收费、不承诺现实证明效力
- 不做真实背景调查、信用查询
- 不替代各署业务数据主库，只做归档与查询视图

## 前台用户端功能

1. **档案与记录署首页**：服务目录、办事指南
2. **我的档案**：档案目录、按署分类、按时间筛选、记录摘要
3. **记录查询**：签注记录、入境记录、居民记录、外交记录、文书记录、活动记录、申诉记录
4. **记录详情**：只读展示，跳转原业务署详情；脱敏字段
5. **下载与导出**：单条记录下载、档案汇总导出（PDF/CSV，需限流）
6. **档案证明申请**：选择证明类型、关联记录、提交申请、联动文书认证署
7. **数据删除/注销申请**：申请范围、影响说明、确认、进度查询
8. **档案验真**：输入档案编号/证明编号查询，脱敏展示
9. **消息与帮助**：申请结果、删除进度、常见问题
10. **个人中心**：聚合我的档案、证明、删除申请

## 后台管理端功能

1. **归档规则配置**：各署归档字段、归档周期、保留策略
2. **归档任务管理**：手动/定时归档、失败重试、归档日志
3. **档案查询**：按用户、编号、业务类型查询；敏感字段脱敏；导出需审批与审计
4. **档案证明管理**：模板、生成、撤销、验真配置
5. **数据删除/注销处理**：受理、审核、执行、回执、审计；区分软删除与物理删除
6. **访问日志**：谁查了谁的档案、何时、原因
7. **风控**：查询频率限制、批量导出限制、异常查询告警、防枚举
8. **统计报表**：归档量、查询量、下载量、证明量、删除申请量
9. **审计管理**：敏感操作审计、隐私影响评估记录

## 系统能力

- 统一账号与 SSO 接入
- RBAC 权限，档案查询员、删除处理员、管理员队列隔离
- 归档任务调度、归档状态机
- 档案编号/证明编号不可猜测生成
- 只读查询视图，不复制业务主数据
- 数据删除状态机：待受理、审核中、执行中、已完成、已拒绝
- 与各署数据接口、与文书认证署证明联动
- 文件私有存储、审计日志、限流、错误码、软删除

## 与其他署联动

| 联动方 | 联动内容 |
|---|---|
| 全部业务署 | 读取业务记录做归档与查询视图 |
| 文书与认证署 | 档案证明认证与验真 |
| 申诉与监察署 | 删除申请被拒可申诉 |
| 个人中心 | 聚合我的档案、证明、删除申请 |
| 统一验真中心 | 档案证明编号验真 |
| 管理后台 | 提供归档与访问审计数据 |

## MVP 建议先做

1. 首页 + 我的档案目录
2. 签注/入境两类记录归档与查询、详情跳转
3. 单条记录下载、档案汇总导出（限流）
4. 数据删除/注销申请受理与进度
5. 后台归档规则、归档任务、档案查询、访问日志
6. 审计日志、权限隔离、脱敏、限流

后续再做：全署归档、档案证明认证、验真、保留策略、物理删除、批量导出审批、统计报表。

# 四、奶龙国皇家统计署

## 定位与边界

**定位：** 平台数据统计与年度报告模块，主要作为后台数据看板和前台趣味年度报告，不对外提供真实统计数据，不做现实统计调查。

**做什么：**
- 平台运营数据看板：申请量、通关量、活动量、居民数等
- 各署统计报表汇总
- 年度报告/个人年度报告（趣味化）
- 数据导出（需审批与审计）
- 统计口径管理
- 公示性趣味统计（脱敏、聚合）
- 为管理后台提供统一统计能力

**不做什么：**
- 不发布真实社会经济统计数据
- 不做真实统计调查、人口普查
- 不提供第三方数据服务
- 不展示可识别个人的数据
- 不收费、不承诺数据权威性
- 不替代各署业务报表，只做汇总与展示

## 前台用户端功能

1. **统计署首页**：趣味统计展示、年度报告入口
2. **平台趣味统计**：注册用户数、签注签发量、通关量、活动数、徽章发放量（聚合脱敏）
3. **个人年度报告**：我的签注、入境、打卡、活动、徽章、居民/外交身份等年度汇总；可分享图片（带水印）
4. **数据说明**：统计口径、更新时间、免责声明
5. **消息与帮助**：年度报告生成通知、常见问题

## 后台管理端功能

1. **统计口径管理**：指标定义、计算公式、数据来源、更新频率
2. **看板管理**：各署看板、平台总看板、自定义看板
3. **报表管理**：日报/周报/月报/年报、定时生成、订阅
4. **数据导出**：导出审批、脱敏规则、导出日志
5. **年度报告配置**：模板、指标、生成任务、分享图配置
6. **数据质量**：缺失、异常、口径不一致检查
7. **权限**：统计查看权限、导出权限、看板权限
8. **审计管理**：导出审计、敏感指标访问审计

## 系统能力

- 统一账号与 SSO 接入
- RBAC 权限，统计查看、导出、管理员分离
- 指标计算任务、聚合脱敏
- 报表模板引擎、年度报告生成
- 与各署数据接口（只读聚合）
- 审计日志、限流、错误码

## 与其他署联动

| 联动方 | 联动内容 |
|---|---|
| 全部业务署 | 读取聚合数据做统计 |
| 个人中心 | 聚合个人年度报告入口 |
| 文化旅游署 | 打卡、徽章统计 |
| 礼宾与活动署 | 活动、报名统计 |
| 管理后台 | 提供统一看板与报表 |
| 申诉与监察署 | 提供审核时效、异常操作统计 |

## MVP 建议先做

1. 后台平台总看板：签注、入境核心指标
2. 各署基础报表：申请量、通过率、处理时长
3. 统计口径说明、脱敏规则
4. 导出审批与日志
5. 个人年度报告 v1（趣味化、可分享图）
6. 审计日志、权限隔离、限流

后续再做：多署看板、定时报表订阅、数据质量、自定义看板、更多年度报告指标。

# 五、奶龙国皇家教育与科学署

## 定位与边界

**定位：** 世界观知识、科普内容与学习任务模块，负责奶龙国百科、问答、科普文章、学习任务和成就。它是内容型扩展，不涉及真实学历教育、科学研究和学术认证。

**做什么：**
- 奶龙国世界观百科、词条
- 科普/文化文章、专题
- 问答互动、知识小测（与考试署区分：教育署偏学习，考试署偏资格）
- 学习任务、阅读打卡、成就
- 内容收藏、分享
- 内容审核与举报
- 与考试署题库联动（学习内容支撑考试）

**不做什么：**
- 不涉及真实学历教育、学校、学位
- 不做真实科学研究、学术出版、同行评议
- 不颁发真实学历、学位、培训证书
- 不收费、不做真实课程交易
- 不收集真实学历、真实学校信息
- 不承诺现实教育或学术效力

## 前台用户端功能

1. **教育与科学署首页**：百科入口、科普专题、学习任务
2. **百科/词条**：分类、搜索、词条详情、关联词条、收藏
3. **科普/文化文章**：文章列表、详情、专题、收藏、分享
4. **问答互动**：提问、回答、点赞（需审核，可选）
5. **知识小测**：趣味小测、答题、解析、成绩（非资格）
6. **学习任务**：阅读任务、打卡、完成记录、成就徽章
7. **收藏与历史**：收藏内容、阅读历史
8. **内容举报**：举报违规内容
9. **消息与帮助**：任务完成、徽章获得、内容更新；常见问题
10. **个人中心**：聚合我的学习、收藏、任务、徽章

## 后台管理端功能

1. **词条管理**：创建、编辑、审核、上下线、版本
2. **文章/专题管理**：发布、审核、上下线、分类
3. **问答管理**：审核、屏蔽、举报处理
4. **知识小测管理**：题目、组卷、发布
5. **学习任务管理**：任务、条件、奖励、统计
6. **内容审核**：敏感内容、违规内容、举报处理
7. **风控**：发布频率限制、垃圾内容识别、黑名单
8. **统计报表**：阅读量、收藏量、任务完成率、举报量
9. **审计管理**：内容审计、版权说明

## 系统能力

- 统一账号与 SSO 接入
- RBAC 权限，内容编辑、审核员、管理员分离
- 内容状态机：草稿、待审核、已发布、已下线
- 任务状态机、徽章发放
- 与考试署题库联动（学习内容引用）
- 文件私有存储、站内信、审计日志、限流、错误码、软删除
